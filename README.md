# CampNet

CampNet is a friendly campus community prototype for Ahmadu Bello University, Zaria. It is designed around the small everyday things that make university life feel connected: finding people with shared interests, seeing what is happening on campus, joining conversations, and keeping up with events.

This front-end demo includes a polished sign-in experience, a sample student profile, campus posts, circles, events, notifications, messages, search, profile editing, light and dark themes, and responsive navigation for smaller screens.

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Select **Take a look around** to explore with the sample student profile.

No installation, server, database, or real account is required. Demo profiles and activity are stored only in your browser's local storage.

## Built with

- HTML
- CSS
- Vanilla JavaScript

## Important note

CampNet is a front-end concept, not a production authentication system. Do not enter a real password or personal information into the demo. A production version would need a secure back end, verified university access, and proper privacy protections.
